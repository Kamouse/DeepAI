# DeepAI
TP1 - Alexandre Andreani , Nicolas Coutot

## IA :
Utilisation de l'IA sur le fichier Conversation pour créer les différentes commandes tel que /aide, /historique, /changer etc...
Également sur le fichier Main pour Register.

## Comment ça marche ?
Lancer le fichier main,
choisir dans le terminal un modèle (tapper 1,2 ou 3)
écrire un message
utiliser des commandes comme /historique pour voir l'historique des messages
/aide pour lister les commandes
/solde pour connaitre son solde
/changer pour changer de modèle IA
/quitter pour arreter la conversation.
